# SQL — 100 End-to-End Projects

A library of **100 self-contained SQL projects**, each a complete mini-database built the same way:

| File | What it holds |
|---|---|
| `01_schema.sql` | Tables, keys, constraints |
| `02_indexes.sql` | Index strategy for the workload |
| `03_analytics.sql` | Reporting / analytical queries |
| `04_procedures.sql` | Stored procedures & functions |
| `05_seed_data.sql` | Realistic sample data |
| `data_source.csv` | Source data used for seeding |

## Domains covered

Hospital management, e-learning, supply chain, core banking, smart parking IoT, flight reservation, hotel booking, food delivery, ride sharing, e-commerce inventory, digital wallet, CRM pipeline, insurance claims, loan origination, crypto exchange, stock trading, telecom billing, EV charging stations, drone delivery — and ~80 more, from `project_001_hospital_management` to `project_100_waste_recycling_hub`.
